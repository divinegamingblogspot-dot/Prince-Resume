ME N U — Personal AI System

Private zero-cost Google Sheets + Apps Script companion system

A personal system combining memory, tasks, coins/shop logic and AI-style interaction inside a spreadsheet workflow.

Deep dive

System concept

Use Google Sheets as a lightweight interface and data store, with Apps Script handling commands, tasks, memory and controlled interactions.

Features

Memory-oriented data, tasks, coins/shop logic, questions and answers, voice-oriented interaction and an AI-style assistant layer.

Engineering constraint

Designed around a zero-cost approach and lightweight components rather than requiring a paid backend.

Outcome

A highly customized example of using familiar business tooling as a programmable personal application.

How it fits the bigger picture

This build is part of a broader toolkit connecting business operations, data, automation, AI, software and web engineering.
